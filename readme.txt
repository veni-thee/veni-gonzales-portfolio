Veni Gonzales — Portfolio (2026 refresh)

A Salesforce-themed static portfolio site, styled with the Salesforce
Lightning Design System (SLDS) over a Salesforce brand color palette.

Pages:
  index.html     About / profile / contact
  work.html      Work experience timeline, certifications, skills, projects
  nonwork.html   Values, beliefs, hobbies
  thank-you.html Contact form confirmation page

Stack:
  - SLDS (via CDN, @salesforce-ux/design-system)
  - Font Awesome 4.7 (icons)
  - Vanilla HTML/CSS/JS — no build step, deployable as-is on GitHub Pages

Hosted on GitHub Pages.
